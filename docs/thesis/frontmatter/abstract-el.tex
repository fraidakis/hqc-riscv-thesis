\chapter*{Περίληψη}
\addcontentsline{toc}{chapter}{Περίληψη}

Η παρούσα διπλωματική εργασία παρουσιάζει μια end-to-end βελτιστοποίηση του
μετα-κβαντικού μηχανισμού ενθυλάκωσης κλειδιού \HQC σε αρχιτεκτονική RISC-V,
αξιοποιώντας τις ratified κρυπτογραφικές επεκτάσεις \Zbc, \Zvbc, \Zbb και \Zvbb.
