\chapter*{Περίληψη}
\addcontentsline{toc}{chapter}{Περίληψη}

Η παρούσα διπλωματική εργασία παρουσιάζει την πρώτη πλήρως βελτιστοποιημένη υλοποίηση σε καθαρό λογισμικό του
μετα-κβαντικού μηχανισμού ενθυλάκωσης κλειδιού \HQC σε αρχιτεκτονική RISC-V,
αξιοποιώντας τις ratified επεκτάσεις ISA \Zbc και \Zvbc (carry-less multiplication) καθώς και \Zbb και \Zvbb (bit manipulation). Σε επίπεδο HQC-128, η πλήρως διανυσματική υλοποίηση (Tier~3) επιτυγχάνει επιτάχυνση \speedup{296} στον πολυωνυμικό πολλαπλασιασμό και \speedup{154} στο πλήρες KEM ως προς τη διανυσματική αναφορά, σε επίπεδο instruction count (\instret). Σε υψηλότερο επίπεδο ασφάλειας (HQC-256), η αντίστοιχη επιτάχυνση στο πλήρες KEM ανέρχεται σε \speedup{317}. Τα μεγέθη Tier~3 ποσοτικοποιούν τον αλγοριθμικό αριθμό εντολών (\instret) στον \gls{iss}· η επικύρωση σε επίπεδο κύκλων σε πραγματικό RISC-V silicon παραμένει μελλοντική εργασία.
