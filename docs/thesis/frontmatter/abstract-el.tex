\chapter*{Περίληψη}
\addcontentsline{toc}{chapter}{Περίληψη}

Στην παρούσα διπλωματική εργασία αναπτύσσεται η πρώτη πλήρως βελτιστοποιημένη υλοποίηση σε καθαρό λογισμικό του
μετα-κβαντικού μηχανισμού ενθυλάκωσης κλειδιού (KEM) \HQC σε αρχιτεκτονική RISC-V.
Η υλοποίηση αξιοποιεί τις εγκεκριμένες (ratified) επεκτάσεις της αρχιτεκτονικής συνόλου εντολών (ISA) \Zbc και \Zvbc (carry-less multiplication) καθώς και \Zbb και \Zvbb (bit manipulation). Σε επίπεδο HQC-128, η υλοποίηση που αξιοποιεί όλες αυτές τις επεκτάσεις επιτυγχάνει επιτάχυνση \speedup{307} στον πολυωνυμικό πολλαπλασιασμό και \speedup{164} στο πλήρες KEM ως προς τη μη βελτιστοποιημένη αναφορά, σε επίπεδο instruction count (\instret)· το όφελος διατηρείται και στα τρία επίπεδα ασφάλειας (HQC-128/192/256), φτάνοντας \speedup{331} στο HQC-256. Πέρα από τον προσομοιωτή συνόλου εντολών (ISS), οι μετρήσεις επικυρώνονται σε πραγματικό RISC-V silicon (Banana Pi BPI-F3, SpacemiT K1): πλήρης ανταλλαγή κλειδιού HQC-128 σε $\approx\SI{1.3}{\milli\second}$ στα \SI{1.6}{\giga\hertz} (\speedup{34.3} έναντι αναφοράς). Η cycle-accurate επικύρωση του πλήρως διανυσματικού variant αναμένει silicon που υλοποιεί \Zvbc/\Zvbb.
