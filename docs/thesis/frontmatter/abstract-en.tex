\chapter*{Abstract}
\addcontentsline{toc}{chapter}{Abstract}

This thesis develops the first optimized pure-software (no specialized hardware) implementation of HQC, a post-quantum \gls{kem}, on RISC-V. The implementation leverages the ratified \gls{isa} extensions
Zbc and Zvbc (carry-less multiplication) as well as Zbb and Zvbb (bit manipulation). At the HQC-128 level, the optimized implementation achieves a \speedup{307} speedup on polynomial multiplication and \speedup{164} on the full \gls{kem} relative to the HQC team's reference implementation, measured in instruction count (\instret). This benefit is sustained across all three security levels (HQC-128/192/256), reaching \speedup{526} on polynomial multiplication and \speedup{331} on the full KEM at HQC-256. Beyond the \gls{iss}, the measurements are evaluated on real RISC-V silicon (Banana Pi BPI-F3, SpacemiT K1). As the available hardware does not yet support the Zvbc/Zvbb vector extensions, a not-fully-optimized version is run on the available silicon, achieving \speedup{34} at HQC-128 over the reference.
