\chapter*{Abstract}
\addcontentsline{toc}{chapter}{Abstract}

This thesis develops the first fully optimized pure-software implementation of the HQC post-quantum
\gls{kem} on RISC-V. The implementation leverages the ratified \gls{isa} extensions
Zbc and Zvbc (carry-less multiplication) as well as Zbb and Zvbb (bit manipulation). At the HQC-128 level, the implementation exploiting all of these extensions achieves a \speedup{307} speedup on polynomial multiplication and \speedup{164} on the full \gls{kem} relative to the unoptimized scalar reference, measured in instruction count (\instret); this benefit is sustained across all three security levels (HQC-128/192/256), reaching \speedup{331} at HQC-256. Beyond the \gls{iss}, the measurements are validated on real RISC-V silicon (Banana Pi BPI-F3, SpacemiT K1): a full HQC-128 key exchange completes in $\approx\SI{1.3}{\milli\second}$ at \SI{1.6}{\giga\hertz} (\speedup{34.3} over the reference). Cycle-accurate validation of the fully vectorized variant awaits silicon implementing Zvbc/Zvbb.
